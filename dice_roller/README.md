# Lanceur de Dés pour JDR

Ce dossier contient un petit programme de lancer de dés pour vos sessions de Jeu de Rôle.

## Comment l'utiliser (sur Windows)

Comme il n'a pas été possible de créer un fichier `.exe` unique, voici la méthode pour lancer le programme. Cela ne prend que quelques minutes la première fois !

### Étape 1 : Installer Python

Si vous n'avez pas Python sur votre ordinateur, il faut l'installer.

1.  Ouvrez votre navigateur internet et allez sur le site officiel de Python : `https://www.python.org/downloads/windows/`
2.  Cliquez sur le lien "Latest Python 3 Release".
3.  Descendez en bas de la page jusqu'à la section "Files".
4.  Cliquez sur **"Windows installer (64-bit)"** (ou 32-bit si votre ordinateur est plus ancien).
5.  Une fois le fichier téléchargé, ouvrez-le.
6.  **TRÈS IMPORTANT :** Dans la première fenêtre d'installation, cochez la case en bas qui dit **"Add Python to PATH"** ou **"Ajouter Python au PATH"**. C'est essentiel.
7.  Cliquez ensuite sur "Install Now" et suivez les instructions.

### Étape 2 : Lancer le programme

Maintenant que Python est installé, c'est très simple.

1.  Assurez-vous que ce fichier `README.md` et le fichier `main.py` sont dans le même dossier (par exemple, un dossier `dice_roller` sur votre Bureau).
2.  Ouvrez ce dossier.
3.  Dans la barre d'adresse de l'explorateur de fichiers (là où est écrit le chemin du dossier, ex: `C:\Users\VotreNom\Bureau\dice_roller`), cliquez sur l'espace vide à droite du nom du dossier.
4.  Effacez le texte, tapez `cmd` et appuyez sur la touche Entrée.
5.  Une fenêtre noire (l'invite de commande) va s'ouvrir.
6.  Dans cette fenêtre noire, tapez la commande suivante et appuyez sur Entrée :
    ```
    python main.py
    ```
7.  Le programme se lancera !

Vous n'avez besoin de faire l'étape 1 qu'une seule fois. Pour relancer le programme, il suffit de refaire l'étape 2.
